# Two-minute judge demo

0–15s: “A BitLocker policy incident is easy to diagnose once. Our goal is to automate the engineering delivery of safe, repeatable tooling for a class of incidents.” Show 47 synthetic records.

15–35s: “We gave Obvious three narrowly scoped engineering tasks.” Show task assignments and agent workstreams in the **actual Obvious interface**.

35–75s: Show TASK-01 incident findings, TASK-02 fixture-based diagnostic JSON, and TASK-03 human-review-only remediation proposal, as completed (do not claim anything incomplete).

75–100s: Show GitHub PRs, automated CI results, reviewer feedback, and what was actually merged. Give exact counts only if verified.

100–120s: “The output isn't a single prompt result. It's an auditable workflow that can repeat across new tickets without granting agents authority to modify endpoints.” Enter a new task in Obvious and show the new workflow beginning if available.

If some tasks remain unfinished: acknowledge the real state, show the finished outputs and test evidence, and explain scope cuts. Never display mocked PR metrics as real.
